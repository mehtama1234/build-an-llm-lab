One block.

Attention lets tokens read each other — but that alone isn't a layer. The real repeating unit of a transformer wraps attention and a small per-token network together, held stable by two quiet pieces: residual connections and normalization. Build this one block, stack it, and you have the whole model. Every number below is a real run.

What a block is made of

Four parts, one unit

A transformer block has exactly four moving pieces. Two you've met; two are new here:

1 · attention tokens mix information across the sentence (Sessions 4–5)
2 · feed-forward each token is transformed on its own (new)
3 · residuals a bypass that keeps the original vector alongside each step (new)
4 · layer norm rescale activations to a stable size (new)

Attention = mixing across tokens. Feed-forward = thinking within a token. Residuals + norm = what makes a deep stack of these actually trainable.

Part 2 — the feed-forward network

Expand, bend, contract — per token

After attention has mixed context in, each token is passed independently through a tiny 2-layer network: project up to 4× the width, apply a nonlinearity, project back down. It's where the model does its per-token "thinking." Run on the real cat vector:

in · 50↑ expand ×4 hidden · 200 → GELU↓ contract out · 50
96/200 hidden units activein‖ 4.41out‖ 2.4

Same in and out size (50), so blocks chain cleanly. The nonlinearity (GELU) is what lets it learn something other than a plain linear map — about half the hidden units fired for this input.

The nonlinearity

GELU — a softer gate than ReLU

The bend in the feed-forward network is GELU. Like ReLU it lets big positive values through and suppresses negatives — but smoothly, with a slight dip below zero instead of a hard corner. That smoothness gives cleaner gradients. Real curve:

at x=-0.5 → GELU -0.154 vs ReLU 0.0at x=2 → GELU 1.955 vs ReLU 2.0

Near zero GELU is gentle (a small negative x isn't slammed to exactly 0), which keeps a little gradient flowing where ReLU would give none.

Part 4 — layer normalization

Reset every vector to a common scale

Before each sub-step, LayerNorm takes a token's vector and re-centers it to mean 0 and rescales it to standard deviation 1 (then a learned scale & shift the model can tune). It stops any one dimension from blowing up and keeps every layer seeing inputs at a predictable size. The real cat vector, first 12 of 50 dims:

before — mean 0.048, std 0.621
after — mean -0.0, std 1.0

Same shape, retuned scale: mean pulled to ~0, spread set to exactly 1. Nothing about which dimension is biggest changes — only the overall size.

Why residuals + norm exist — the real proof

Without them, depth kills the signal

Here's the whole argument in one experiment. Push a vector through 40 layers and watch its size, three ways: plain (no residual), residual only, and residual + LayerNorm. Then do the same for the gradient (what training actually needs to flow back). Real numpy, log scale:

plainresidual onlyresidual + LayerNorm
signal @40: 0.0 / 24,263,522 / 8.0 gradient @40: 0.0 / 1,792,196 / 5.24875

This is exactly why a block has all three

Plain (rose) collapses to 0 — the signal and its gradient vanish, so a deep stack can't learn. Residual only (amber) fixes the vanishing by adding an identity bypass — but now nothing bounds the size, so it explodes to millions. LayerNorm (cyan) rescales after each step, holding both signal and gradient steady. Residuals keep the signal alive; normalization keeps it in check. You need both — that's the block.

Putting it together

The data flow through one block

Modern GPTs put the norm before each sub-step (pre-norm) and add the bypass around it. Read top to bottom — the + is where the residual rejoins:

token vectors in
↓
LayerNorm → attention → + residual
↓
LayerNorm → feed-forward → + residual
↓
context-rich vectors out

Same size in as out — which is the whole point: the output of one block is a valid input to the next.

Why it's called the repeating unit

Stack it — that's the model

The body of a GPT is just this one block, copied and stacked. GPT-2 small stacks 12; the largest GPT-2, 48; big modern models, dozens more. Each block re-reads the sentence and refines every token a little further:

12 identical blocks (GPT-2 small). Nothing new after this — depth is just more of the same unit. Now you can see why residuals + norm mattered: without them, 12 stacked layers would strangle the signal.

The one-line aha

A block is attention (mix across tokens) + a feed-forward net (think within each token), wrapped in residuals that keep the signal alive and normalization that keeps it in check — the one unit you stack to build the whole model.
