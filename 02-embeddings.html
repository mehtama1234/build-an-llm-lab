Numbers become meaning.

Session 1 turned text into token IDs. But an ID like 9379 is an arbitrary label — it isn't "close to" 262 in any way that means anything. So the next step gives every token a vector — a position in space — where meaning becomes geometry: similar words point the same way. Every number below is from real 50-dimensional word vectors.

The idea, in plain words

Each id is looked up into a vector

The model holds an embedding table: one learned vector per token. To use a token, you take its id and grab that row — a list of numbers. Here's the real vector for king:

"king"→ id691→ row 691 of the table →
0.50.69-0.6-0.020.6-0.13-0.090.47… +42

50 numbers (GPT-2 uses 768). On their own they're meaningless — the meaning is in where this vector points relative to others.

Why not just use the id?

An id is a name, not a place. cat=id A and dog=id B tells the model nothing about them being alike. A vector puts them somewhere — and "alike" becomes "nearby." That geometry is the only thing the next stage (attention) can compute on.

Watch it happen

Similar words point the same way

Measure the angle between two vectors (cosine similarity: 1 = same direction, 0 = unrelated). Real numbers from the vectors — related words score high, unrelated words low:

king · queen0.78
king · man0.53
king · banana0.22
cat · dog0.92
cat · car0.36
three · four0.99
paris · france0.80
happy · sad0.69
happy · joyful0.56

cat·dog 0.92 and three·four 0.99 — nearly the same direction. king·banana 0.22 — near-perpendicular. The model never told them these facts; the geometry learned them.

The big picture — see it

Meaning has a shape

Take 20 words, squash their 50-D vectors down to 2-D (so we can look), and plot them. Nobody labeled these groups — the words land near others that mean something similar:

kingqueenprinceprincessthronecatdoghorsecowliontigeronetwothreefourfivefrancegermanyjapanchinaindia
royaltyanimalsnumberscountries

Real 50→2-D projection (PCA). Royalty, animals, numbers, countries each pull into their own region — meaning became a map.

The part that feels like magic

Relationships are directions you can do math on

If meaning is geometry, then relationships are consistent directions — and you can add and subtract them. The direction from man→woman is the same move as king→queen. Real vector arithmetic, nearest word to the result:

king − man + woman≈queen0.86
paris − france + italy≈rome0.84
walking − walk + swim≈swimming0.81
bigger − big + small≈larger0.90

Each result is the real nearest vector to the computed point (with its cosine). The "gender" direction, the "capital-of" direction, the "-er/comparative" direction — all just vectors.

The one-line aha

An id is a name; an embedding is a place. Once every token is a point in space, "similar" becomes "nearby" and "relationship" becomes "direction" — and that geometry is what the whole model computes on.
