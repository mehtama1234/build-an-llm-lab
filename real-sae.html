Unpacking a neuron's many meanings.

Last time we hit a wall: a single neuron fires for a jumble of unrelated things, because the model packs far more ideas than it has neurons (superposition). Reading it directly is hopeless. Here we run the actual tool interpretability teams built to get around this — a sparse dictionary — on real GPT-2, and watch its tangled activations come apart into features you can name.

The idea

Give it thousands of slots, but only let a few switch on

The model's working memory at each word is a list of 768 numbers (the “residual stream”). Those 768 numbers carry many overlapping ideas at once. The trick: learn a much wider vocabulary — 4,096 candidate features — but with a hard rule that only 32 may be active for any one word. Then train those features for one job: add up the 32 active ones and rebuild the original 768 numbers.

Why does that force meaning apart? If only 32 slots can ever be on, the cheapest way to reconstruct everything the model says is to make each slot stand for a distinct, recurring pattern — a specific word, a kind of word, a bit of grammar. Sparsity is the pressure that turns a blurry mix into a list of separate things. Nothing tells it what the features should be; it discovers them from the model's own activations.

Honest caveats

This is a scaled-down version of the real thing

Ours is a small dictionary (4,096 features) trained on a small amount of text (79,248 words) for a few minutes on a laptop CPU. Frontier labs train dictionaries of millions of features on billions of tokens. So expect rough edges: some features are still mixed, 949 slots never learned anything, and rarer concepts don't get their own feature at this scale. The lesson isn't that this dictionary is perfect — it's that the method works even here: sparsity genuinely pulls readable features out of a representation that was unreadable one coordinate at a time.

Why this matters
  • It closes the loop from last time. Neurons looked hopelessly polysemantic because meaning is superposed. A sparse dictionary is the way out — it recovers the separate ideas the model had packed together.
  • This is how models are actually read today. The features here are the same kind of object interpretability teams use to find, name, and even steer concepts inside frontier models.
  • It's learned, not labeled. No one told it “make a feature for numbers.” Under nothing but a reconstruct-with-few-active-slots pressure, nameable structure fell out on its own.
Connecting it back

Experiment #3 ended on a problem — the model's neurons don't line up with human ideas. This is the resolution: change the basis. Ask for a wide vocabulary that must stay sparse, and the tangled activations of a real model separate into features you can read off one by one — recovered, provably, from GPT-2's own numbers (90% rebuilt from 32 of 4,096).
