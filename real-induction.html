An attention head with an algorithm.

We keep saying attention lets words "look at each other." But is a head ever doing anything we'd recognize as clever — or is it just fuzzy averaging? This experiment catches a single head in real GPT-2 running a crisp, nameable procedure: copy what came next last time.

The specific clever thing

Copying a pattern it has seen once

Here's a concrete skill worth having: if you've just seen a pattern, be able to continue it. In "…the secret code is Vpharnix … the secret code is ___", the answer is Vpharnix — and the only way to know that is to have noticed it earlier in this very text. Nothing about GPT-2's fixed, trained weights knows that made-up word; the answer has to be pulled from the prompt itself.

To do that, a head has to run a precise little routine: at the second "…code is", look back to what followed the first "code is", and copy it forward. That's not vague averaging — it's an algorithm you can state in one sentence and then go check for.

Experiment A — does it copy? (real GPT-2)

Same head, on readable made-up words it has never seen — it still copies:

“…s Vpharnix. I repeat, the secret code is”→ V 0.65
“…to the market. Later that day, Zylthorpe”→ was 0.10

The first copies the invented code straight out of the prompt. (The second is a fuzzier case — the model prefers a natural continuation over a literal copy; induction competes with everything else the model wants to do, it doesn't always win.)

Why this one matters so much

This is where in-context learning comes from

A head that copies "what followed this last time" is a general-purpose pattern-continuer. It's not tied to any specific words — give it any repeated structure and it extends it. This single mechanism is a big part of why models can pick up a pattern from your prompt (a format, a list, a translation style) and keep it going without any training — the learning happens inside the forward pass, by looking back. Heads like this one are believed to be a core engine of that ability.

  • Attention is not just soft averaging. A single head can implement a sharp, statable algorithm — and you can find it, score it, and watch it run.
  • Nothing here was cherry-picked. The 0%→96% jump, the head ranking, and the stripe are all direct reads from real GPT-2 on random inputs.
  • It's the small model. The effect is already crisp at 124M; in bigger models these heads are stronger and more numerous.
Connecting it back

Sessions 4–5 showed attention as a mechanism. This shows it as a program: one head in a real model runs "copy what came next last time," proven by a 0%→96% jump on repeated randoms and drawn as a clean stripe in its attention. The heads don't just relate words — some of them compute recognisable algorithms, and this particular algorithm is much of how a model learns from its own prompt.
